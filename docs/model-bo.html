Bayesian Optimization 기반 NCM811 합성 조건 추천 READ-ONLY DEMO

문헌·실험 데이터로 학습된 Random Forest surrogate가 사용자가 지정한 합성 조건 탐색 범위에서 예측 방전 용량 상위 3개를 반환합니다.

인터랙티브 데모

모델 데모를 불러오는 중…
모델 정보. Surrogate: scikit-learn RandomForestRegressor (n_estimators=500, random_state=0). 학습 데이터: NCM811 합성·전기화학 평가 문헌 + 사내 BO 실험 결과 누적 데이터. 입력 공간: 4 범주형(전구체) + 6 정수(수열·1차·2차 소성 온도/시간). 출력 단위: mAh/g (0.1 C-rate 기준).

안전성. 본 데모는 옵티마이저 상태 파일을 로드하지 않으며, 사용자 입력은 surrogate predict에만 사용됩니다 (BO 루프의 opt.tell() 호출 없음 = 상태 오염 0).
