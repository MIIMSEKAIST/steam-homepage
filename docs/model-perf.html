셀 설계·공정 변수 기반 배터리 성능 예측 LIVE · API

전극 로딩·두께·공극률·입자 크기와 캘린더링·코팅·건조·화성 조건, 평가 조건을 입력하면 C-rate별 방전 용량, 초기 사이클 손실, 율속 특성, 사이클 수명을 예측합니다. 공개 실험 데이터(WMG 캘린더링·코팅 DoE, U-Mich formation)와 PyBaMM Li-metal 하프셀 시뮬레이션으로 학습한 프로토타입이며, 1단계 상용셀 화성 DB·차세대 파우치 데이터 수신 후 같은 스키마로 재학습(v2)됩니다.

모델 유형
Random Forest multi-target (타깃별 500 trees, ±σ = 트리 분산)
입력
범주 4 (양극·음극·셀 형태·화성) + 설계·공정·화성·평가 조건 수치 (결측 허용)
출력
용량 vs C-rate 곡선, 초기 손실, 율속(5C/0.2C), 수명(80 % 도달 cycle, 300 cycle 유지율)
런타임
STEAM 통합 백엔드 (FastAPI · 버전 레지스트리 · 핫 리로드)

③ 예측 결과

프리셋을 고르거나 값을 입력한 뒤 성능 예측 실행을 누르세요.
예측 방전 용량 vs C-rate (mAh/g, 활물질 기준)
예측 평균±1σ (트리 분산)입력 C-rate
학습 데이터 (공개). 모델 정보를 불러오면 표시됩니다.

평가 지표. 전극 조건·셀·설계 단위 GroupKFold 교차검증으로 MAPE·MAE·R²(스칼라/수명), 셀별 율속 곡선 RMSE(mAh/g)를 산출합니다 (계획서 핵심 보완 계획 (1): 스칼라·수명 = MAPE + MAE, 곡선 = RMSE, 조건 템플릿 명시). 5–10C에서 용량이 0에 가까운 셀 때문에 전체 MAPE는 과대 평가되므로 ≤ 2C MAPE를 함께 봅니다.

조건 템플릿.

한계. 소규모·이종 공개 데이터(3개 기관 + 1 시뮬레이션)로 학습했으며, 각 타깃은 해당 항목을 측정한 데이터 소스에서만 학습됩니다. 다른 셀 계열 입력은 외삽으로 표시됩니다. Li-metal(sim) 결과는 물리 시뮬레이션(DFN 하프셀) 기반이며 실측 검증 전입니다. 차세대 배터리 조립 규격 → 성능 예측(2단계 4차년도 계획)의 인터페이스·스키마·파이프라인 검증용 프로토타입입니다.
